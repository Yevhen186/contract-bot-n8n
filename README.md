# Contract Bot — n8n

Telegram-бот для автоматичної генерації логістичних договорів.
Будував як реальний інструмент для роботи, паралельно вчився автоматизації.

## Що робить

Менеджер пише в Telegram реквізити компанії та дані рейсу —
бот повертає готовий .docx договір за ~30 секунд.

Без бота: вручну заповнювати Word-шаблон ~15 хвилин + ризик помилок.
З ботом: вставив текст → отримав файл.

## Як працює

1. Менеджер обирає компанію та роль (Замовник або Перевізник)
2. Надсилає реквізити звичайним текстом — не потрібен жодний формат
3. Groq (LLM) парсить текст і витягує потрібні поля в JSON
4. Бот копіює шаблон у Google Drive, замінює всі плейсхолдери через Docs API
5. Експортує як .docx і надсилає в чат

## Стек

- **n8n** — вся логіка workflow, хостинг на Railway
- **Telegram Bot API** — інтерфейс для менеджерів
- **Groq API** (llama-3.3-70b) — парсинг вільного тексту в JSON
- **Google Docs API** — заміна плейсхолдерів у шаблоні
- **Google Drive API** — копіювання шаблонів, видалення тимчасових файлів
- **Google Sheets** — зберігання стану сесії кожного користувача

## Варіанти договорів

| Компанія | Роль | Особливості |
|----------|------|-------------|
| АвтоМув | Замовник | ФОП, без ПДВ, внутрішні + міжнародні |
| АвтоМув | Перевізник | + поле вартості вантажу |
| ЮТС | Замовник | з ПДВ, тільки внутрішні |
| ЮТС | Перевізник | з ПДВ, тільки внутрішні |

## Як запустити

1. Імпортуй `Contract Bot.json` в n8n (Import → from file)
2. Створи credentials: Telegram Bot, Google Sheets, Google Drive, Google Docs, Groq (HTTP Header Auth)
3. Заміни `YOUR_SESSIONS_SPREADSHEET_ID` на свій Google Sheets ID
4. Додай свої шаблони .docx у Google Drive, встав їх ID у вузол `Copy file`
5. Активуй workflow
